# Wx3000 區網隨身碟安裝與部署指南 (Customer LAN Installation Guide)

> 本指南說明如何將打包完成的 `Wx3000\publish\` 目錄複製到隨身碟，並在客戶端的**區網主機 (Server)** 與**員工工作站 (Client)** 進行安裝。

---

## 📋 一、出發前：隨身碟檔案檢查清單

在開發機執行根目錄的 `Wx3000-Manager.bat` 完成打包（選單 `[5]`、`[8]`、`[9]` 或 `[10]`）後，請將整個 **`Wx3000\publish`** 資料夾複製到隨身碟。

確認隨身碟的 `publish\` 目錄內包含以下結構：

```text
publish\
├── Install-Wx3000.bat             # ★ 雙擊啟動安裝精靈 (自動取得系統管理員權限)
├── Install-Wx3000.ps1             # PowerShell 安裝主程式
├── README_客戶端安裝指南.md       # 本安裝說明文件
├── Wx3000_Server\
│   └── api\                       # [選單 5 產出] 後端服務執行檔與 wwwroot 前端網頁
├── localagent\
│   └── dist\                      # [選單 8 產出] Wx3000Agent.exe、wbaseRP.dll、DBFBridge.exe 等
└── frontend\
    └── Electron\
        └── release\               # [選單 9/10 產出] win-unpacked 免安裝版或 Setup 安裝檔
```

> 💡 **為什麼要用 `Install-Wx3000.bat` 安裝？**
> 切勿直接在隨身碟上註冊 Windows 服務！因為隨身碟拔除後服務就會失效。
> `Install-Wx3000.ps1` 會自動將所需檔案從隨身碟複製到客戶電腦的本機硬碟（預設為 **`C:\Wx3000\`**），並自動完成服務註冊、防火牆設定與桌面捷徑建立（`w3000_dbf.dll` 搭配 `w3000_dbf.VBR` 為免註冊元件，直接複製即可運作）。

---

## 🖥️ 二、步驟 1：安裝區網【主機電腦 (Server)】

區網內會有 **1 台主要電腦（主機）** 負責存放 PostgreSQL 資料庫與原 FoxPro `C:\w3000\comm\*.dbf` 資料。

### 1. 前置確認
- 確認主機已安裝並啟動 **PostgreSQL 16**（預設 Port `54320` 或依 `appsettings.json` 設定）。
- 確認舊系統 DBF 目錄（如 `C:\w3000\comm\`）存在且可讀寫。

### 2. 執行一鍵安裝
1. 將隨身碟插入主機電腦，打開隨身碟的 `publish` 資料夾。
2. 滑鼠雙擊執行 **`Install-Wx3000.bat`**（若跳出 UAC 權限視窗請點選「**是**」）。
3. 在安裝選單輸入 **`1`** 並按 `Enter`：
   - **選擇 `[1] ★ 安裝【主機端 Server 全套】 (後端服務 + LocalAgent + Electron 桌面端)`**
4. 安裝程式會自動完成以下動作：
   - 複製後端與網頁至 `C:\Wx3000\Server\api\`。
   - 註冊並啟動 **`Wx3000Api`** Windows 服務（設為開機自動啟動），並開放 Windows 防火牆 **TCP Port `5007`**。
   - 複製 LocalAgent（含免註冊元件 `w3000_dbf.dll` / `w3000_dbf.VBR` 與 `wbaseRP.dll`）至 `C:\Wx3000\LocalAgent\`，並設定開機背景啟動 **`Wx3000Agent.exe` (Port `18889`)**。
   - 複製桌面端至 `C:\Wx3000\Client\`，並在桌面建立 **【Wx3000 雲端會計進銷存】** 捷徑。
5. **抄下畫面顯示的「本機伺服器區網網址」**（例如：`http://192.168.1.100:5007`），待會員工電腦連線會用到！

## 💻 三、步驟 2：安裝區網【其他員工工作站 (Client)】

區網內其他會計/記帳人員的電腦，不需要安裝後端與資料庫，只需要安裝 **Electron 桌面端** 與 **LocalAgent 本機印表代理**（讓員工電腦可以彈出 Lazarus FastReport 報表預覽視窗與直印）。

### 1. 執行工作站一鍵安裝
1. 將隨身碟插入員工電腦，打開隨身碟的 `publish` 資料夾。
2. 滑鼠雙擊執行 **`Install-Wx3000.bat`**。
3. 在安裝選單輸入 **`2`** 並按 `Enter`：
   - **選擇 `[2] ★ 安裝【區網員工工作站】 (LocalAgent 本機印表代理 + Electron 桌面端)`**
4. 安裝程式會自動將檔案複製到員工電腦的 `C:\Wx3000\LocalAgent` 與 `C:\Wx3000\Client`，並建立桌面捷徑。

### 2. 設定連線至主機 IP（首次開啟設定一次即可）
1. 雙擊員工電腦桌面的 **【Wx3000 雲端會計進銷存】** 捷徑開啟程式。
2. 在鍵盤按下快捷鍵 **`Ctrl + Shift + S`**（或點選左上角選單「**系統 (S)**」➔「**伺服器連線設定 (C)**」）。
3. 輸入剛剛在主機抄下的區網網址（例如：`http://192.168.1.100:5007`）並儲存，畫面即會自動重新載入並連上主機！

> 🌐 **備註（免安裝桌面端改用瀏覽器）**：
> 如果員工習慣直接用 Chrome / Edge 瀏覽器，也可以直接在瀏覽器網址列輸入 `http://192.168.1.100:5007` 使用（但若該台員工電腦需要列印中一刀/FastReport 報表，仍需在該電腦執行選單 `[5]` 安裝 LocalAgent）。

## 🔄 四、日後到場更新維護 (只更新部分模組)

日後若有程式修改，將更新後的 `publish` 拷貝到隨身碟後，執行 `Install-Wx3000.bat` 可直接選擇單獨更新：

- **選單 `[3]`**：只更新主機的後端 API 與網頁（會自動先停 `Wx3000Api` 服務、覆蓋檔案後再重啟服務）。
- **選單 `[4]`**：只快速熱更新主機的前端網頁檔 `wwwroot`（不重啟後端服務）。
- **選單 `[5]`**：只更新本機的 `LocalAgent` 報表 DLL 與橋接程式。
- **選單 `[6]`**：只更新本機的 `Electron 桌面端`。
- **選單 `[8]`**：隨時查看本機服務是否正常運行，以及查詢本機的區網 IP。

## 🛠️ 五、常見問題排除 (Troubleshooting)

1. **員工電腦連不上主機 (`http://主機IP:5007`)？**
   - 在主機執行 `Install-Wx3000.bat` ➔ 選擇 **`[8]`** 確認 `Wx3000Api` 狀態為 `運行中 (Port 5007)`，並確認主機 IP 是否正確。
   - 若主機有安裝第三方防毒軟體（如趨勢、卡巴斯基、ESET），請確認防毒軟體防火牆允許 TCP Port `5007` 連入。
2. **按下 `F7` 列印報表時沒有跳出預覽視窗？**
   - 報表預覽是由操作者電腦本機的 `LocalAgent` (`localhost:18889`) 呼叫 `wbaseRP.dll` 產生。
   - 請確認該台電腦已執行過安裝選單的 `[2]` 或 `[5]`，且 `Wx3000Agent` 顯示為 `運行中`。
3. **後端需要修改資料庫密碼或連線 Port？**
   - 主機安裝完成後，設定檔位於 `C:\Wx3000\Server\api\appsettings.json`。修改後在 `Install-Wx3000.bat` 執行重啟或於 Windows 服務重啟 `Wx3000Api` 即可生效。
